# TG 视频下载 · 使用说明（接收方版）

> 适用于 `tg-video-dl` **v0.4.2** 的 fpk 包。
> 这是一个飞牛 fnOS 应用：**把 Telegram 收藏夹里的视频/电子书自动下载到你的 NAS**。

---

## 0. 安装前先确认（不满足就别装了）

| 项 | 要求 | 说明 |
|---|---|---|
| NAS 架构 | **x86_64** | 包内 `manifest` 写死 `platform=x86`，ARM 机型（含部分飞牛 ARM 版）装不上 |
| 飞牛系统版本 | **≥ 1.2.0401** | `os_min_version` |
| 网络 | 需要能访问 `pypi.org`（首次启动） | 首次启动会联网安装 Python 依赖，**这一步失败 = 应用起不来** |
| Telegram 账号 | 你自己的号 + 能拿到 `api_id/api_hash` | 见 [第 3 步](#3-第二步telegram-登录) |
| 代理节点 | **必须有一个 v2ray 节点**（vless/vmess/trojan/ss） | 国内 NAS **直连不了 Telegram**，代理不是可选项 |
| 权限 | 管理员账号 | 安装应用、改应用授权目录都需要管理员 |

---

## 1. 安装

1. 把 `tg-video-dl-0.4.2.fpk` 传到 NAS（文件管理器上传或 SMB 拷进去都行）。
2. 飞牛桌面 → **应用中心** → 右上角 **手动安装** → 选这个 `.fpk`。
3. 会弹一条安装说明（就是下面这些要点），点继续/完成。
4. **依赖应用会自动装**：本应用依赖 `python312`，应用中心会自己准备；如果提示缺失，按提示先装它。
5. 装完**先别急着用**——首次点「打开/启动」时，应用会在后台建 Python 环境（跑 pip 装依赖），
   通常 **1～3 分钟**。这段时间面板可能打不开或转圈，是正常的。
   - 判断依据：应用能打开、**运行状态**卡显示版本号 `v0.4.2`，说明环境已就绪。

> 给别人的包**文件名带版本号**，新版是不同文件名：以后更新直接「手动安装」新包即可覆盖，**不用先卸载**。

## 2. 你要准备的两样东西

### 2.1 `api_id` / `api_hash`（Telegram 官方应用凭据，免费）

1. 浏览器打开 **https://my.telegram.org** （**国内网络通常打不开，需挂代理**）。
2. 用你的 TG 手机号登录 → 第一次会收到 TG 里的一条登录码。
3. 点 **API development tools** → 随便填个 App title / Short name → 创建。
4. 记下 **`api_id`**（一串数字）和 **`api_hash`**（32 位字母数字）。
5. ⚠️ 新申请的 `api_id` 有时会有一小段**限制期**，导入/登录可能偶发失败，等一会儿重试即可。

> 用**你自己**的 `api_id`。不要用别人给的——那等于把号挂在别人名下。

### 2.2 v2ray 节点（必需）

- 从你的机场/自建节点复制 **分享链接**，形如：
  - `vless://uuid@host:443?security=reality&pbk=...&fp=chrome#节点名`
  - `vmess://...` / `trojan://...` / `ss://...` 也支持
- 一条链接对应一个节点；**填哪个节点就用哪个出网**。
- 如果你已经有别的代理（比如飞牛上跑着 clash 的 http/socks 端口），本应用**不能直接用它**——
  它只认 v2ray 分享链接（自带 xray 客户端）。

## 3. 打开应用，按顺序配 4 步

打开方式：飞牛桌面 → 应用 → **TG 视频下载**（左侧面板「代理 → Telegram 登录 → 下载设置」是编号顺序，照 1→2→3 走）。

### 第一步：代理（v2ray 分享链接）

| 字段 | 填什么 |
|---|---|
| **分享链接** | 粘贴第 2.2 步拿到的 v2ray 链接（**已设置过时留空 = 不修改**） |
| **出网方式** | 保持 `v2ray`（只有你确认家里网络能直连 TG 时才选 `direct`） |
| **本机 SOCKS 端口** | 默认 `10808`，不用改 |

点 **「保存并启动代理」** → 下方应该出现连通性检查结果，面板顶部「代理」灯变绿。
也可以用 **「测试 Telegram 连通性」** 单独验证。

> 保存后节点信息会加密落盘（AES-GCM），不会明文写日志、也不会回显明文。

### 第二步：Telegram 登录

1. 填 **`api_id`**、**`api_hash`**、**手机号（带国际区号，如 `+8613800138000`）**。
2. 点 **「保存凭据」** → 再点 **「发送验证码」**。
   - 验证码是发到 **你的 Telegram 客户端**里的（登录码消息），不是短信。
3. 在「验证码」框填 **5 位数字**，点 **「提交验证码」**。
4. 如果你的号开了**两步验证（2FA）**，会出现「两步验证密码」输入框，填上再提交。

成功标志：面板顶部「Telegram」灯变绿，登录卡片显示已登录。

### 第三步：下载设置

| 字段 | 建议 | 说明 |
|---|---|---|
| **落盘目录（视频）** | 留空 或 填你自己的目录 | 留空 = 应用私有目录 `/vol*/@appdata/tg-video-dl/downloads`（**无需任何授权**，最省事） |
| **文档落盘目录** | 留空 = 跟视频同目录 | 想单独放电子书就填一个**已被系统授权**的目录（见第 4 节） |
| **路径模板（视频）** | `{date}/{filename}` | 支持 `{date} {chat} {filename} {ext} {id}` |
| **文档路径模板** | `{filename}` | 默认只留 TG 原文件名，方便下游程序按名导入 |
| **文档后缀白名单** | `.txt,.epub,.pdf,.mobi,.azw3` | 留空 = **只下 .txt**；字幕/封面（.srt/.jpg/.nfo…）永远不下 |
| **并发数** | `1`（别调高） | 调高更容易触发 TG 限流（flood-wait） |
| **磁盘最低剩余** | `5` GB | 低于此值拒绝下载 |
| **断点续传** | 开 | 中断后从 `.part` 继续 |
| **视频回报进度** | 开 | 在收藏夹里编辑同一条消息显示进度 |
| **文档完成后回报** | 开 | 文档只报「完成」，避免刷屏 |
| **文档也回报进度** | 关 | 电子书小，刷屏 |

填完点 **「保存设置」**。填了目录的话，先点旁边的 **「检查目录」** 看是否可写。

### 第四步：开启监听

点 **「开启收藏夹监听」**（面板上「收藏夹监听总开关」）。这是**总闸**——不开的话转发什么都不会下载。

## 4. 需要授权什么（重点）

### 4.1 应用自带、无需你操作的

安装时系统会按包内声明自动处理，你不用管：

| 声明 | 作用 |
|---|---|
| `run-as=package`（用户/组 `tgvdl`） | 应用以**非 root** 低权限用户运行 |
| `data-share` | 系统给应用一个专属共享目录 |
| `api-scope`：`trim.file.path`、`trim.system.getPlatformConfig` | 只用来做路径展示和读系统信息，**不读你的文件** |
| 网络 | 应用需要出网（走你自己填的节点） |

### 4.2 只有这一件需要你手动授权：**要往你自己的目录写文件时**

如果你接受默认的**应用私有目录**（第 3 步里落盘目录留空），**不需要任何授权**，到此结束。

如果你要让视频/电子书落到**你自己的存储目录**（比如 `/vol2/1000/影视`），必须做两步：

1. 飞牛 **设置 → 应用 → TG 视频下载** → 添加**可访问的目录**（勾上你要用的那个目录）。
2. 回 **应用中心 → 停止 → 再启动** 本应用。

> ⚠️ **第 2 步不能省**：目录授权是在**应用启动时**注入的，不重启不生效。
> 现象就是"我明明授权了，面板还报不可写"。

**怎么验证授权好了**：回到面板第 3 步，点 **「检查目录」**：
- 显示 **`✓ 可写`**（可能还带 `✓ 在系统授权目录内`）→ 成功；
- 还报 `Permission denied` / 未授权 → 检查上面两步，特别是**有没有重启应用**。

**一个坑**：fnOS 的目录授权有时**只体现在系统组/ACL 层**（把你的目录授权给应用用户），
环境变量里看不到——所以判断标准是**面板的写探针结果**，不是别的。

**文档目录更严格**：文档落盘目录**必须**落在"系统授权目录"内，否则保存时就直接被拒绝（报 `need_auth`）。
省事做法：**文档目录留空**，电子书就跟视频落同一个目录，无需额外授权。

## 5. 怎么用

1. 手机/电脑 Telegram 里找到想下的**视频或文档**。
2. **转发到「收藏夹」（Saved Messages，即自己的号）**。
   - ⚠️ 只认**收藏夹**。转发到群、频道、别人的私聊都**不会**触发下载。
   - 你要下什么，得先自己找到再转发——本应用**不做搜索/发现**。
3. 应用监听到就自动排队下载，面板 → **「下载记录」**可以看进度：
   - 统计：总计 / 已完成 / 进行中 / 排队中 / 失败；导航上还有个红色徽标提示失败数。
   - 单条失败可以重试；也可以「重试全部失败」「清空已完成」。
4. 下载完成（若开启了回报）会在**收藏夹里**出现一条「完成」消息。

**下载能力边界**：单文件上限 **2 GB**（走 TG 用户号）。别指望下超大文件。

## 6. 上手验收清单

按顺序做一遍，全绿就算配好了：

- [ ] 应用能打开，运行状态显示 `v0.4.2`
- [ ] 代理灯**绿**；「测试 Telegram 连通性」通过
- [ ] 登录灯**绿**，显示已登录
- [ ] 落盘目录点「检查目录」→ `✓ 可写`（用自定义目录时）
- [ ] 已点「开启收藏夹监听」
- [ ] 手机转发一个**小视频**到收藏夹 → 「下载记录」出现任务 → 完成 → NAS 上能看到文件
- [ ] 再转发一个 `.txt` 或 `.epub` → 落到文档目录（或视频目录）

## 7. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 应用打不开、面板转圈 | 首次启动在装依赖，等 1～3 分钟；超过 5 分钟还没好 → 多半是访问不了 `pypi.org`（见下条） |
| 日志里 pip 超时/连不上 | NAS 到 PyPI 不通。给它配好网络/代理后再重启应用；或换个能通的时段重试 |
| 代理灯灰 / 连通性测试失败 | 节点本身不可用，或分享链接格式不对（先点「仅校验链接」）。换节点重试 |
| 收藏夹转发后毫无反应 | ① 没开「收藏夹监听」；② 转发的是**群/频道**而不是收藏夹；③ 是订阅/图片等不支持类型；④ 磁盘剩余低于阈值 |
| 「已授权但报不可写」 | 授权后**没重启应用**（授权在启动时注入）；或目录路径写错了 |
| 保存文档目录被拒（need_auth） | 该目录不在系统授权目录内 → 去 设置 → 应用 授权，重启；或留空跟视频同目录 |
| 登录卡住 / 收不到验证码 | 验证码发在 **TG 客户端**里不是短信；确认手机号带 `+86`；`api_id` 新申请可能有短暂限制期 |
| 下到一半停了 | 看「下载记录」和日志；断点续传默认开启，重试会从 `.part` 继续 |
| 同名文件 | 默认**不覆盖**，自动改名 |
| 想看日志 | 面板底部「运行日志」，可选来源与行数 |

## 8. 更新与卸载

- **更新**：拿新版 `.fpk`（文件名带版本号）→ 应用中心「手动安装」→ 直接覆盖，**无需卸载**。
- **卸载**：应用中心卸载。卸载时按提示选择是否保留数据；
  `.secrets.yaml`（含 TG session、节点链接）存在应用数据目录里，**卸载时建议一并删除**。

---

## 9. 账号安全（务必看）

- 本应用持有你的 **Telegram 用户号 session**（这是能下载 2GB 文件的前提，
  Bot 只有 20MB 上限）。**拿到 session 就等于能操作你的号**。
- session 与节点链接加密存在 NAS 上（AES-GCM，文件权限 600），日志脱敏、面板不回显明文。
- 因此：**只装你信任的人给的包**；不把 NAS 的应用数据目录随便共享给别人；
  手机丢失或怀疑泄露时，在 TG 里「设备 → 终止其他会话」即可吊销（应用需重新登录）。
- 用**自己的** `api_id/api_hash`，不要用别人分享的。
