1代理（v2ray 分享链接）

粘贴一条分享链接，应用会自己启动内置 xray 出网，不需要你在 NAS 上另装代理软件。
支持 vless:// vmess:// trojan:// ss://； reality 与带 fp= 指纹的节点也能用（由 xray 处理）。

2Telegram 账号登录

下载必须走用户号（MTProto），因为 Bot API 的下载上限只有 20MB，而 TG 视频基本都超。
在 my.telegram.org → API development tools 免费申请 api_id 与 api_hash（几分钟出结果）。
登录后 session 会AES-GCM 加密保存在应用私有目录（权限 600），不会写进日志、也不会下发到本页面。

3下载设置

开启监听后，把想下载的视频或电子书文档（TXT/EPUB/PDF…）转发到自己的收藏夹（Saved Messages），应用即会自动落盘。 一期只监听收藏夹，不订阅任何群或频道（尽量降低账号风控风险）。
路径模板可用字段：{date} 日期、{filename} 文件名、 {ext} 扩展名、{chat} 来源、{id} 消息 ID。 想按媒体库惯例归档可写 电影/{filename}（视频）、书库/{filename}（文档）。
文档后缀白名单：只有命中白名单的文档才会下载（默认 .txt,.epub,.pdf,.mobi,.azw3）； 字幕/封面等附属文件（.srt .ass .vtt .jpg .png .nfo）永远不下。

4下载任务

转发到收藏夹的视频/文档会出现在这里。转发后无需任何操作，应用会自动识别并入队。 重复转发同一条消息不会重复下载（按消息 ID 去重）。
